# 拼好汉化工作台 UI 演示

这是 React/TypeScript 编写的可点击界面原型，不是可用的汉化工具。
不读取游戏、不调用 API、不保存密钥、不生成真实成品。演示输入仅存在当前页面内存，刷新重置。

在本目录运行 `npm ci --legacy-peer-deps`、`npm run dev`，访问终端给出的本机地址。
锁定依赖时跳过不使用的可选同伴依赖，避免自动安装测试浏览器等外围组件。
`npm run build` 执行类型检查并构建静态预览；`npm run preview` 可以查看构建结果。
当前不安装 Electron 外壳，避免为界面评审下载整套桌面运行时；此界面后续可接入 Electron。

可查看游戏项目、制作总览、文字工作台、验收输出、游玩辅助和设置。
新建向导、页面切换、上下文面板、字体选择、问题筛选和暂停/继续状态均为 UI 交互。
所有模拟动作明确标为演示，不代表当前已支持任何引擎或已通过验收。

视觉方向：白色纸面、墨黑文字、印红操作色，辅以少量金色；左侧固定导航，中心完成当前任务，右侧呈现上下文。
侧栏顶部使用用户提供的原图，通过 CSS 裁切成144px圆标，保留四字、红印与外围文字；点击图标或软件名返回首页。
文案直接说明用途与动作，顶栏统一标识“界面预览”。模型设置分为技术适配、翻译、校对润色，
每项可独立选择模型并配置专用接口；这些设置在本次页面会话中保留。
模型连接的高级设置提供全局并发，初始默认3项，可调整并在切页后保留。金额预算已移除；
产品提示词由内置任务规则提供，默认制作页展示这一约定。实际调度和提示词装配仍由后续内核实现。
界面字体有意采用 Windows 中文 UI 字体，正文预览可选择楷体和黑体。
不使用真实游戏封面、台词、译文或私人文件路径。
