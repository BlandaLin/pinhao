upstream artwork and aspect ratio. Engine names and marks belong to their
respective owners; the image licenses are separate from Pinhao's software license.

## Additional Engines

WOLF RPG Editor, TyranoScript, Kirikiri/KAG, Pixel Game Maker MV, Smile Game
Builder and RPG Developer Bakin currently use Pinhao's neutral engine symbol
alongside their original names. Dedicated brand assets can be added with an
upstream source and documented redistribution terms.
