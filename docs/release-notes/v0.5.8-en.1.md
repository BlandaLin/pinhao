## English

The English edition of Pinhao 0.5.8 includes translated navigation, settings, dialogs, production progress, the Text Workbench, Builds & Export, and Play Assistance.

### Download and Use

Download [`pinhao-0.5.8-en-Windows-x64.zip`](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/pinhao-0.5.8-en-Windows-x64.zip), extract the whole package to a writable folder, and run `PinhaoWorkbench.exe`. Requires Windows 10/11 x64. [Source code](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/pinhao-0.5.8-en.1-source.zip) and [checksums](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/SHA256SUMS.txt) are also available.

**New settings default to translating games into English (`en`).** To change the target, open **Settings → Advanced settings → Target language**. Existing saved language choices and project targets are preserved.

Enter your own model connection in Settings and try a small project first. Keep the original game and saves, then check the finished copy's dialogue, choices, fonts, and save/load. Official downloads are free; model requests are billed by your provider.

The [Chinese edition](https://github.com/BlandaLin/pinhao/releases/tag/v0.5.8) remains available. Game text, existing translations, names, paths, and technical evidence keep their original content when you open a project in the English UI.

### Feedback

Report problems through [Issues](https://github.com/BlandaLin/pinhao/issues/new/choose). Include the edition, game and engine, steps, and a screenshot of the affected screen. Redact keys and personal details; keep full games, API settings, and private projects out of public reports.

Complex resources and game-specific plugins still need adaptation. The original 0.5.8 automated checks have [four unresolved failures](https://github.com/BlandaLin/pinhao/blob/main/docs/release-notes/v0.5.8.md#known-issues).

## 中文

这是 0.5.8 的英文界面版，覆盖导航、设置、对话框、制作进度、文字工作台、成品导出和游玩辅助。

### 下载与使用

下载 [`pinhao-0.5.8-en-Windows-x64.zip`](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/pinhao-0.5.8-en-Windows-x64.zip)，完整解压到可写文件夹后运行 `PinhaoWorkbench.exe`。支持 Windows 10/11 x64，另附[源码](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/pinhao-0.5.8-en.1-source.zip)和[校验文件](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/SHA256SUMS.txt)。

**新配置默认把游戏翻译为英语（`en`）。** 可在 **Settings → Advanced settings → Target language** 更改目标语言；已有的语言选择和工程目标保留。

在设置中填写自己的模型连接，先用小项目确认效果。保留原游戏与存档，检查成品的对白、选项、字体和存读档。官方软件免费，模型请求按服务商规则收费。

[中文版](https://github.com/BlandaLin/pinhao/releases/tag/v0.5.8)仍可下载。用英文界面打开工程时，游戏文字、既有译文、名称、路径和技术记录保持原内容。

### 问题反馈

通过 [Issues](https://github.com/BlandaLin/pinhao/issues/new/choose) 提供版本、游戏与引擎、操作步骤和出错界面截图。先遮盖密钥和个人信息；不要公开上传完整游戏、API 配置或私人工程。

复杂资源和游戏专有插件仍有适配缺口。原 0.5.8 自动化检查的 [4 项失败](https://github.com/BlandaLin/pinhao/blob/main/docs/release-notes/v0.5.8.md#known-issues)尚未解决。

## Build From Source / 从源码构建

Prepare the dependencies in the [desktop guide](https://github.com/BlandaLin/pinhao/blob/main/apps/desktop/README.md), then keep the English setting in the same PowerShell session for build and packaging:
按照[桌面开发说明](https://github.com/BlandaLin/pinhao/blob/main/apps/desktop/README.md)准备依赖后，在同一 PowerShell 会话执行：

```powershell
$env:PINHAO_UI_LANGUAGE = "en"
npm run build
npm run package
```

For the default Chinese build, clear the language variable first / 默认中文构建先清除语言变量：

```powershell
Remove-Item Env:PINHAO_UI_LANGUAGE -ErrorAction SilentlyContinue
```
