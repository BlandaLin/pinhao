## English

This is the English-interface edition of Pinhao 0.5.8, published under the separate tag **`v0.5.8-en.1`**. It provides a real English desktop UI, including **Getting Started**, **Overview**, **Start translation & review**, **Builds & Export**, settings, dialogs, and application status messages.

Download [`pinhao-0.5.8-en-Windows-x64.zip`](https://github.com/BlandaLin/pinhao/releases/download/v0.5.8-en.1/pinhao-0.5.8-en-Windows-x64.zip) for Windows 10 / 11 x64. Extract the whole package to a writable location and run `PinhaoWorkbench.exe`. The original [Chinese v0.5.8 release](https://github.com/BlandaLin/pinhao/releases/tag/v0.5.8) and its downloads remain unchanged.

**Fresh settings default the game's translation target to English.** You can choose another target in Settings; existing choices and project targets are not overridden. The default Chinese build still uses Simplified Chinese. Game source text, existing translations, names, paths, IDs, and engine-facing values are not translated by the interface layer, and the model communication protocol is unchanged. This update's verification made **no model API calls**, paid or otherwise.

This remains a public beta. Keep the original game and saves, and try a short scene before a full project. Official downloads are free; model services may charge when you use technical investigation, translation, or proofreading.

## Build From Source / 从源码构建

After preparing the documented dependencies, keep the language setting in the **same PowerShell session for build and packaging**:

准备好[源码构建依赖](../../README.en.md#development-and-further-reading)后，在**同一 PowerShell 会话**内设置语言并执行构建、打包：

```powershell
$env:PINHAO_UI_LANGUAGE = "en"
npm run build
npm run package
```

For the default Chinese build, clear the variable first / 恢复默认中文构建前先清除变量：

```powershell
Remove-Item Env:PINHAO_UI_LANGUAGE -ErrorAction SilentlyContinue
```
