### 翻译与校对

- 模型正文回包改为短标记纯文字分段，不再要求复制长 ID、JSON 引号或空备注。软件在本地恢复工程定位并检查遗漏、控制符和冲突。
- 校对只返回需要修改的文字和明确完成标记，不再逐条抄写全部已审阅编号。准确的译文保持原样；空回复不算审阅通过。
- 初翻与校对中断时，完整返回且通过检查的成果继续保存。恢复请求只补未完成目标，不重新购买已经接受的改文。
- 同批重复背景合并，正文语境与工程证据分开；完整证据仍可按需补查。分批估算区分实际输出负担，不为凑批次切碎完整语义单元。
- 保留初翻后的译名统计及场景校对，只复核真实译名分歧与明确问题，不额外追加全量人物术语再审。

### 技术 Agent 与原生工具

- 统一默认容量、压缩预留和发送前检查，阻止回复空间被夹到不可用后仍反复发送请求。大工具结果完整保存，再提供可继续读取的位置。
- 修复容器成员与物理资源定位在验证、汇总、接入和回写间丢失的问题。Windows 长路径与目录真实身份在相关处理链中统一。
- CSV/TSV 增加精确单元格适配和独立结构检查，保护键、列及未选内容。自定义分隔协议不会因为文件扩展名相同被标准 CSV 解析替代。
- Unity 多语言表可选择一个来源语言；增加已证明加载、拆分和显示消费链的完整正文提取。文件名含 `Localization` 不再单独授权所有字符串作为待译文字。
- MV 命令正文、RGSS 静态显示常量和 Godot 静态场景/脚本数据增加来源追踪。未知逻辑用途仍交技术 Agent 调查，不为增加条数强行接纳。
- 归档工具增加分页索引与选定成员读取，减少整包媒体展开。部分重包核对原包并保留未选成员，分别报告实际读写能力。

技术 Agent 仍可调查未知格式、运行工具和编写适配器；这些更新没有收回其通用执行权限。

### 成品与手机包

- MV/MZ 本地化与游玩辅助插件并入标准静态插件表，保留第三方顺序、启用状态和参数；不执行未知动态配置。
- 对能够证明的数据库名称逻辑依赖，使用原名身份处理资源查找和逻辑比较，显示继续采用译名。未知消费者单独报告，不全局替换 `name()`。
- JoiPlay `.rga` 导出检查资源缺失、排除、文件名大小写和 OGG/M4A 候选。预检只报告问题，不自动改名、转码或补造缺失媒体。
- 中英文状态提示与阶段进度同步；“已审阅”与“校对已完成”分别表示暂存审阅和正式提交，文字工作台可筛选对应结果。

### 验证范围

本次更新包含针对协议、恢复、容量和接入的隔离检查，以及真实资源的只读调查与隔离原生回写复验。原生增强的最终合并检查通过 148 项 Node 和 61 项 Python 测试，桌面构建与公开源码检查通过。这些结果不代表所有游戏剧情、存读档或手机设备均已验证。

## English

0.6.0 combines the translation protocol, recovery, capacity handling, native parser, and build-check updates made after the public 0.5.8 release. Chinese and English portable editions share this release page and have the same features.

### Download and Update

Choose the interface edition in the table above, extract the whole ZIP on Windows 10/11 x64, and run `PinhaoWorkbench.exe`. Keep the app's `data` folder and existing project folders. Pause tasks and close the old app before updating. New settings default to English in the English edition and Simplified Chinese in the Chinese edition; existing target-language choices are preserved.

**Official builds are free. Do not pay to buy the official package. You supply the model API; its provider determines API charges.** The source ZIP is for development, and `SHA256SUMS.txt` contains download checksums.

### Translation and Proofreading

- Translation replies use short-marked plain-text blocks instead of long IDs, JSON-escaped text, and empty notes. The app restores writeback locations and checks omissions, controls, and conflicts locally.
- Proofreading returns corrections and an explicit completion marker, not a copied list of every reviewed ID. Correct translations remain unchanged. An empty reply does not count as a completed review.
- Complete, validated results survive interrupted translation and proofreading replies. Resumed requests cover unfinished targets rather than redoing accepted corrections.
- Shared background is sent once per batch, separately from engineering evidence. Full evidence remains available for follow-up reading. Batch estimates account for output load without splitting complete semantic units.
- Name statistics and scene proofreading remain part of the flow. Follow-up checks target real terminology disagreements and identified issues, not an unconditional second full review.

### Technical Agent and Native Tools

- Default capacity, compression reserves, and pre-send checks use consistent limits. The host stops unusably small output requests rather than repeatedly sending them. Large tool results are stored in full and read in sections.
- Container-member and physical-carrier locations survive validation, aggregation, acceptance, and writeback. Relevant Windows paths use consistent long-path and directory-identity handling.
- CSV/TSV cell adapters independently check keys, columns, and unselected content. A shared extension no longer causes standard CSV handling to override a qualified custom delimiter protocol.
- Unity multilingual tables can select one source language. Verified loader, split, and display-consumer patterns support complete text extraction. A `Localization` filename alone no longer authorizes arbitrary strings for translation.
- MV command text, RGSS static display constants, and Godot scene/script data gain display-source tracing. Unresolved logical uses remain technical tasks instead of being accepted to inflate text counts.
- Archives support paged indexes and selected-member reads to avoid expanding unrelated media. Partial repacking checks the original archive and preserves unselected members. Read and write capabilities are reported separately.

The technical Agent retains its general tools, script execution, and unknown-format investigation capabilities.

### Builds and Mobile Packages

- MV/MZ localization and assistance components use the standard static plugin list, preserving third-party order, enabled flags, and parameters. Unknown dynamic configuration is not executed.
- Proven name-based resource lookups and logic use original database-name identities while display keeps translated names. Unknown consumers are reported; `name()` is not globally replaced.
- JoiPlay `.rga` exports check missing or excluded resources, filename case, and OGG/M4A candidates. Preflight reports problems; it does not rename, transcode, or invent missing media.
- Both interfaces use stage-specific progress and distinguish saved scene reviews from formally completed proofreading. The Text Workbench can filter those saved results.

### Verification Scope

This update includes isolated protocol, recovery, capacity, and acceptance checks, plus read-only examination and isolated native writeback of real resources. The final merged native-parser check passed 148 Node and 61 Python tests; desktop build and public-source checks passed. These checks do not establish that every game, story branch, save operation, or mobile device works.

## 已知问题 / Known Issues

- 自动解析仍有边界：复杂 Unity 自定义加载器、字典和宏链，动态 Godot 消费者、MV 插件专属绘字、MZ 357 插件参数及任意 Ruby 动态脚本不能一概自动接纳。识别引擎不等于完整提取。
- RGSS 原生改文与另一个适配器同时修改同一物理脚本载体时，会报告联合构建冲突，不按最后写入覆盖前者。结构化表格的新适配限 UTF-8。
- 手机资源预检不是 JoiPlay 实机验收，`phoneRuntimeVerified` 保持 false，直至完成对应设备检查。静态检查不修复原本不存在的资源。
- 图片文字回写限平整背景 PNG 区域；工程目录搬移、特殊字体及自定义加密仍有适配限制。关闭游玩辅助不会撤销已写入的剧情或存档改动。
- 固定规则和背景的稳定排列为服务商缓存提供条件，但不保证命中缓存，也没有承诺统一的费用或速度提升比例。

- Automatic extraction remains bounded: complex Unity custom loaders, dictionaries and macros, dynamic Godot consumers, MV plugin-specific drawing, MZ 357 plugin arguments, and arbitrary dynamic Ruby are not universally accepted. Recognizing an engine does not establish complete extraction.
- Concurrent native and adapter edits to one physical RGSS script carrier report a joint-build conflict rather than overwriting one plan. The new structured-table adapter supports UTF-8.
- Mobile preflight is not device acceptance. `phoneRuntimeVerified` remains false until the target device is checked; static analysis cannot repair resources that do not exist.
- Image-text writeback covers flat-background PNG regions. Project relocation, unusual fonts, and custom encryption still have limits. Disabling assistance does not undo earlier story or save edits.
- Stable prompt prefixes support provider caching opportunities; they do not guarantee cache hits or a fixed cost or speed improvement.

Keep the original game and saves. Check dialogue, choices, branches, fonts, audio, and save/load in the finished copy. Report the version, steps, and error in [Issues](https://github.com/BlandaLin/pinhao/issues/new/choose); redact keys and personal information. Do not publicly upload complete games, private projects, API settings, or saves.
