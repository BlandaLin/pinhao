### 这一版交给你的工作方式

- **提取遇到缺口时，可以继续调查资源。** 技术 Agent 可以查看文件、运行工具并尝试编写适配方案；候选经验证并正式接入，才进入文字工作台。本版技术执行采用 DeepSeek Harness，模型由用户选择，不要求使用 DeepSeek 模型。
- **初翻直接处理正文，专名随项目积累。** 请求保留完整语义单元与必要场景、人物参考，用短标记对齐译文；不先另做一轮付费全量词表整理，工程定位与组装由软件负责。
- **把复核集中到实际分歧。** 场景校对之后，人物与术语检查针对真实分歧和明确问题，不无条件再审全文。“已审阅”是场景结果已保存，“校对已完成”是收尾检查与正式提交完成。
- **保存已有工作，继续制作。** 已接受成果持续保存，暂停后按现有恢复机制接续；局部失败经有限修复后按设置处理，持续接口故障与核心失败明确暂停。工程默认放在游戏旁边，便携程序旁的 `data` 保存设置和轻量索引。

其他改进包括文字工作台页码跳转、阶段进度提示、容器成员定位与回导检查，以及游玩辅助连接、备份恢复等路径。生产包精简开发载荷，保留运行依赖和许可证。

### 适用范围与反馈

引擎列表表示已接入的处理路线，不保证同一引擎的所有游戏都能完整制作。自定义插件、加密资源、动态文字、图片文字、字体布局与游戏专有回想条件仍可能需要处理。

请保留原版与存档，先检查短场景，再批量制作。成品需实际检查启动、对白、选项、分支、字体与存读档。反馈请带版本、引擎、步骤、预期和实际结果，以及脱敏截图；不要公开上传完整游戏、个人工程、API 配置或私人存档。

## English

Pinhao 0.5.8 brings resource processing, model-assisted translation and proofreading, text handoff, and standalone game assembly into one workbench. Start with a short scene, check it in the game, and tell us where you get stuck.

### Download and Start

- **`pinhao-0.5.8-Windows-x64.zip`** is the portable app for Windows 10/11 x64. Extract the entire folder and launch `PinhaoWorkbench.exe`.
- **`pinhao-0.5.8-source.zip`** is source code for reading, development, or building the app; it is not a second runnable download.
- **`SHA256SUMS.txt`** provides the SHA-256 checksums. Use the download links in the table above, or the **Assets** section on the GitHub release page.

**The current app UI is Chinese. An English-language beta is planned, but is not available yet.** Official downloads are free. Your chosen model provider may charge for technical investigation, translation, and proofreading requests.

### How This Version Helps

- **Investigate gaps in text extraction.** The technical Agent can inspect files, run tools, and attempt adapters. Only verified, accepted results enter the text workbench. Technical execution uses DeepSeek Harness; you choose the model, which need not be a DeepSeek model.
- **Translate the text, not the project structure.** Complete text units retain necessary scene and character references. Short labels align returned translations; software handles resource identities and assembly. Name choices accumulate with translations instead of requiring a separate paid full-glossary pass first.
- **Focus follow-up review on actual disagreements.** After scene proofreading, character and terminology checks target conflicting choices and explicit issues, rather than repeating a full review. “Reviewed” means scene results are saved; “Proofreading complete” means final checks and submission are complete.
- **Keep accepted work and continue production.** Accepted results are saved as work proceeds, with the existing pause/recovery mechanism. Persistent connection or core-stage failures pause the affected work. Projects default to folders beside the game; `data` beside the portable app stores settings and a lightweight index.

Other changes cover page-number navigation, stage progress, container-member locations and import checks, and play-assistance connection and backup/restore paths. Packaging removes unneeded development payload while retaining runtime dependencies and licenses.

### Scope and Feedback

Engine routes are not a guarantee of complete localization for every game. Custom plugins, encryption, dynamic or image text, fonts, layout, and game-specific recollection conditions may need further work. Keep the original game and saves, and test a short scene first. Check startup, dialogue, choices, branches, fonts, and save/load in the finished copy.

Report the app version, engine, steps, expected and actual results, and redacted screenshots. Do not publicly upload full games, private projects, API settings, or saves.
