# 拼好汉化 0.5.8 · 公开测试版

Windows 10 / 11 x64 便携版。完整解压后启动 `PinhaoWorkbench.exe`，无需安装开发工具。
官方免费，切勿付费购买官方包；模型 API 按所选服务商计费。

## 这一版的主要变化

- **技术适配使用 DeepSeek Harness。** 保留产品内的资源工具、适配配方、原生验证与文字接入机制；模型由用户选择。引擎指南、真实工具反馈与可恢复任务用于协助调查未知格式，不能把扫描候选当作已接入文字。
- **初翻直接处理正文。** 用短标记对应本地文字，不让模型反复搬运长工程 ID 和定位结构。场景、人物及必要参考保留；专名选择随译文积累，真实分歧进入校对，不再先付费整理整份词表。
- **校对只复核需要复核的内容。** 场景审阅后，人物与术语检查针对实际分歧和明确问题，不无条件再做一遍全量校对。界面区分“已审阅”和“校对已完成”，文字工作台可查看已保存的场景审阅结果。
- **暂停后接着已有成果继续。** 局部失败经有限修复后按设置处理，持续接口故障与核心失败明确暂停；已接受成果持续保存。文字工作台支持页码跳转，进度显示随当前制作阶段变化。
- **工程默认放在游戏旁边。** 便携程序旁的 `data` 保存设置和轻量索引，文字成果、技术产物与恢复资料归属就近工程；按需准备资源，减少重复拆包、上下文保存与构建副本。
- **补齐资源接入与辅助链路。** 改良容器成员定位、受保护内容检查、外部文字包回导、原生工具故障提示及游玩辅助连接、备份恢复等路径；生产包精简不需要的调试和开发载荷，保留运行依赖与许可证。

## 使用边界

引擎列表表示已接入的资源路线，不是“所有游戏都已完整汉化”的保证。自定义插件、加密容器、脚本动态文字、图片文字、Unity 字体与布局、游戏专有回想条件仍可能需要处理。技术候选必须通过验证和接入，才会成为可翻译文字。

公开包不包含游戏本体、个人工程、密钥、译文全文或私人存档。请保留原版与存档，先验证短场景，再批量制作。成品还需检查启动、对白、选项、分支、字体及保存读档；源码测试或回写检查不能代替实际游玩。
