### 主要更新

- **界面说明：** 更新制作总览、设置、文字工作台和游玩辅助的按钮、提示与操作说明，中英文界面保持一致。
- **技术适配：** 采用 DeepSeek Harness 执行文件调查、工具调用和适配器编写，验证通过的文字接入工作台。技术模型由用户选择。
- **翻译校对：** 初翻直接处理正文，人物名和术语随翻译积累；场景校对后只复核译名分歧与明确疑点。
- **进度与恢复：** 展示当前阶段进度，区分“已审阅”和“校对已完成”。已接受成果持续保存，暂停后继续。
- **工程存储：** 新工程与独立成品默认放在游戏旁；程序旁的 `data` 保存配置和项目索引。
- **工作台与辅助：** 增加页码跳转，改进文字工作包回导检查、游玩辅助连接和备份恢复，精简发行包中的开发文件。

先用小项目确认效果，保留原游戏和存档。成品生成后检查对白、选项、分支、字体和存读档；遇到问题请保留工程并[提交反馈](https://github.com/BlandaLin/pinhao/issues/new/choose)。分享前遮盖密钥和个人目录，不要公开上传 API 配置、私人存档或整个工程。

## English

0.5.8 updates technical adaptation, translation and proofreading, project storage, and play assistance. This download has a Chinese interface; the [English-interface edition](https://github.com/BlandaLin/pinhao/releases/tag/v0.5.8-en.1) is available separately.

### Download and Use

Download **`pinhao-0.5.8-Windows-x64.zip`** from the table above, extract the whole package, and run `PinhaoWorkbench.exe` on Windows 10/11 x64. The source ZIP is for development; `SHA256SUMS.txt` contains the download checksums.

Enter your OpenAI-compatible API endpoint, model, and key in Settings, then import a game. New settings in this Chinese edition default to Simplified Chinese as the translation target; you can change it in Settings. Official downloads are free. API costs follow your model provider's pricing.

### Main Changes

- **Interface:** Updated buttons, status messages, and instructions across Overview, Settings, the Text Workbench, and Play Assistance in both languages.
- **Technical adaptation:** DeepSeek Harness runs file investigation, tools, and adapter code. Validated text joins the workbench. You choose the technical model.
- **Translation and proofreading:** First translation processes the text directly and collects name and terminology choices. Follow-up review targets conflicting names and identified issues after scene proofreading.
- **Progress and recovery:** Progress follows the current stage. Saved scene reviews and completed proofreading have separate statuses. Accepted results are saved as work proceeds and retained when you pause.
- **Project storage:** New projects and standalone builds default to folders beside the game. The app's `data` folder holds settings and the project index.
- **Workbench and assistance:** Page-number navigation, text-package import checks, assistance connections, and backup/restore have been improved. Development files have been removed from the portable package.

Keep the original game and saves, and try a small project first. Check dialogue, choices, branches, fonts, and save/load in the finished copy. Keep the project when reporting a problem, and [open an issue](https://github.com/BlandaLin/pinhao/issues/new/choose). Redact keys and personal paths; keep API settings, private saves, and complete projects out of public reports.

## 已知问题 / Known Issues

- 自定义插件、加密资源、动态文字和特殊字体仍有适配缺口，具体范围见[引擎说明](https://github.com/BlandaLin/pinhao/blob/main/docs/product/NATIVE_ENGINES.md)。
- 图片文字回写限平整背景 PNG 区域；复杂背景和其他格式需要另行处理。
- 工程目录暂不支持搬家。移动后请先放回原位置，再打开工程；更新程序时保留 `data` 和工程目录。
- 游玩辅助的保存方式以各项说明为准。关闭实时辅助不会撤销已修改的剧情或存档。

- Custom plugins, encrypted resources, dynamic text, and unusual fonts still have compatibility gaps. See [engine support](https://github.com/BlandaLin/pinhao/blob/main/docs/product/NATIVE_ENGINES.md) for the available routes.
- Image-text writeback covers flat-background PNG regions; other formats and complex backgrounds need separate treatment.
- Project relocation is not supported. Return moved projects to their original location before opening them. Keep `data` and project folders when updating the app.
- Each play-assistance entry explains how its changes are saved. Disabling live assistance does not undo earlier story or save edits.
