# 同一场景的完整接力与错误回包修复

在解压后的教程根目录执行。需要 Python 3.10+，PowerShell 可先设 `$env:PYTHONIOENCODING='utf-8'`。所有 out 都是包外不存在的新目录；重跑请换名字，不覆盖原版或先前成果。

现成示范在 `examples/relay`。18 单元包含前台对话、角色资料、选项和词条；参考回包都是预写的中性文字，不调用 API，不含商业游戏运行器。各阶段差异由实际前后文件计算，不能用改动条数当质量分数。

## 1. 先看目录里的成品过程

1. 读 `examples/relay/README.md`，找到三阶段的 input、reference、accepted 与 changes.json。
2. 对比初翻与校对的角色资料：错误的女性代词被移除；其余初翻译文完整保留。
3. 对比校对与润色的前台对话：句法与礼貌改善，控制符、人称修正和其他条目不丢。
4. 比较坏回包与润色参考回包：坏文件只少一个 LINE 占位符；参考回包恢复它。
5. 查看 final/result.json：只证明数据构建符合规则，不是全文语义或实机通过。

技术人员可用下面命令复现；文字 AI 只需对应阶段的输入包，不需要执行命令。

## 2. 导出初翻任务并接回

```powershell
python lesson.py export-text --stage translation --work examples/relay/lesson/work --glossary examples/relay/lesson/text-ai/glossary.json --out '../relay-practice-translation'
python lesson.py import-text --work examples/relay/lesson/work --text examples/relay/01-translation/reference/return-text.txt --out '../relay-practice-translation-accepted'
```

第一条生成初翻 TASK、READING、术语表、完整 return-text 和技术导出报告。第二条用预写参考模拟接回 AI 的结果。真实使用时，把 text 参数换成 AI 返回的文件。

初翻参考故意留一处人称错误，结构仍合法。教学角色资料明确为男性，但原文简介没有显式代词；校对可用自然省略纠错，而不是程序猜性别。

## 3. 从初翻成果导出校对任务

```powershell
python lesson.py export-text --stage proofreading --work examples/relay/lesson/work --editable '../relay-practice-translation-accepted/editable' --glossary examples/relay/lesson/text-ai/glossary.json --out '../relay-practice-proofreading'
python lesson.py import-text --work examples/relay/lesson/work --text examples/relay/02-proofreading/reference/return-text.txt --out '../relay-practice-proofreading-accepted'
```

检查校对任务的 TEXT：它应保留上一阶段完整译文，而不是原始英文。TASK 应明确只校对文字，不重新初翻。接回的是完整文件，即使只修改一条，也保留其余 17 条。

每阶段 TASK 与 export-report 中的指纹表示实际输入快照。负责人选择并核对当前有效版本；程序不能从目录名或内容猜哪份是“最新”。

## 4. 从校对成果导出润色任务

```powershell
python lesson.py export-text --stage polishing --work examples/relay/lesson/work --editable '../relay-practice-proofreading-accepted/editable' --glossary examples/relay/lesson/text-ai/glossary.json --out '../relay-practice-polishing'
```

校对/润色阶段缺少 editable 参数会直接拒绝；必须写明上一阶段有效目录。文字 AI 只改 TEXT/NOTE，保留 BASELINE、ID、条数、顺序及占位符，不自行重做控制符映射。

## 5. 复现坏回包被拒绝

```powershell
python lesson.py import-text --work examples/relay/lesson/work --text examples/relay/03-polishing/recovery/bad-return-text.txt --out '../relay-practice-rejected'
```

应返回 `ok:false`，退出码 2，提示占位符缺失。本坏回包在写出 editable 前被拒绝，不生成成功结果。不同错误可能留下部分诊断输出，不能把失败目录当有效成果。

不要修改 baseline、manifest、校验器，或改 ID 让它勉强通过。定位到报告中的 ID，连同原文、当前译文和控制符交给文字 AI，只修对应字段。其他译文保留。

## 6. 修复后重新接回与构建

```powershell
python lesson.py import-text --work examples/relay/lesson/work --text examples/relay/03-polishing/reference/return-text.txt --out '../relay-practice-polishing-accepted'
python lesson.py integrate --lesson examples/relay/lesson --editable '../relay-practice-polishing-accepted/editable' --out '../relay-practice-final'
```

这里的润色参考文件也是修复回包：恢复同一条目的 `{{LINE0001}}`，保留其余全部当前译文。应得到 18 单元、18 条相对原始基线的有效改动；其中校对与润色各只改了一条。final/built 是数据，notes.json 单独保存备注，没有播放器。

## 7. 生成自己的另一套完整示范

```powershell
python lesson.py prepare-relay --out '../my-relay-practice'
```

这会实际生成三阶段任务、参考回包、转换、差异、一次预期拒绝和最终 build/verify。输入输出指纹可串联核对，源数据与基线保持不变。它是教学生成器，不是自动翻译器。

真正练习时，不把 reference 答案交给文字 AI。按“导出 → 文字处理 → 接回 → 校验 → 导出下一阶段”推进；有未解决疑点就如实记录。到真实项目，还要做字体、图片、原生导入、启动、旧存档与实际场景验收。
