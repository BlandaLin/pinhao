# 技术验收与分享清单

`build` 成功只是结构闭环完成。按下列项目在测试副本验收，不改玩家唯一存档。

| 检查项 | 最低证据 |
| --- | --- |
| 不改动闭环 | `roundtrip` 逐字节一致 |
| 小样闭环 | 改一条中性技术标记，`build` + `verify`，对应运行位置能显示 |
| 启动与菜单 | 无异常、标题菜单居中/对齐、菜单未溢出 |
| 对话与选择 | 中文、姓名、控制符、分支目标和翻页都正常 |
| 字体 | 实际显示字体含中文；检查缺字、标点、换行、粗体；字体授权可随包分发 |
| 图片与 UI | 图片文字、脚本创建的 UI、宏内按钮文字单列，不算自动完成 |
| 存档 | 新档保存/载入；旧档导入在副本测试，不自动改二进制存档 |
| 回想房 | 名牌、对话插值、道具描述都覆盖；检查字符串来自数据还是存档 |
| 分享包 | 不含个人存档、日志、缓存、用户名路径、API key、翻译工作基线与开发依赖 |

旧存档里的默认人名、昵称和字符串变量可能保留原文。兼容补丁应在载入后/显示时只匹配确定的原版默认值；自定义名字、数值变量、进度开关、物品 ID 不动。不能全局替换存档内任意字符串。具体挂钩点因引擎和游戏而异，本版没有通用存档迁移器。

字体不能只改名称：还需确认引擎实际加载了文件、字形覆盖足够、渲染效果和授权。Unity 的 TMP 字体图集、PGMM 的图像字体等可能要另建资产，不能直接放一个 TTF 就宣告完成。

分享声明可以写在说明文件里：本汉化成果完全免费分享，请勿付费购买；如已付费，请联系卖家或平台申请退款。游戏原作者的署名和说明保持可见。
